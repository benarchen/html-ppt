## 实现结果

### 播放器模式

- 默认 `index.html` 使用 `presentation` 模式，视口内仅一张活动页；其他页设为 `aria-hidden="true"`，不可交互。
- `?mode=render` 是 Preflight、PNG、主题审核和自动化测试使用的显式全页渲染模式。
- 打印媒体恢复全部页面、关闭页面与背景动画，并保持一页一个 16∶9 画布。
- 活动页始终以 1280 × 720 等比缩放；16∶9 视口贴合四边，超宽和 4∶3 视口由当前主题舞台色承接余量，不拉伸或裁切正文。
- 前进键为 `ArrowRight`、`ArrowDown`、`PageDown`、`Space`；后退键为 `ArrowLeft`、`ArrowUp`、`PageUp`、`Shift+Space`；`Home`、`End` 跳转首尾页。
- 滚轮／触控板使用连续手势状态机：累计主轴位移达到 24px 后只切换一页；同方向衰减尾流被抑制；事件间隔达到 56ms 或尾流降到 10px 以下后重新加速到至少 14px 时，立即开始新的同向手势；静默 120ms 后强制复位，反向输入立即重置并允许返回。触控滑动阈值保持 60px。
- 当前页写入 URL hash；合法 hash 恢复对应页，无效 hash 回退第一页。
- 页面进入动画为 340ms 低幅度位移与透明度变化；减少动态效果环境立即切页。

### `cosmic-mint` 0.1.5 候选版

- 演示舞台与活动页面共用一层银河、渐变和稀疏星光背景；3408 × 1732 超宽视口从左到右连续铺满，不再用纯色边带承接余量。
- 每页保留 15 颗确定性主星，但每颗独立设置周期、负延迟、亮度峰值、光晕和 4～12px 小范围漂移，肉眼可辨且不形成快速频闪。
- 保留仅陆地绘制细点阵的右侧地球；海洋留空，地球纹理继续以 48 秒周期缓慢转动。
- 移除固定 `::after` 双流星无限循环。演示会话从 `crypto.getRandomValues` 获取一次种子，再由内部 PRNG 调度波次；每波随机出现 1～3 颗流星，起点、终点、长度、速度和启动偏移均可变化。
- 双栏与对比布局取消剩余高度强制拉伸，卡片高度由内容决定，同一行保持等高；长内容仍受页面安全区约束。
- 所有主星删除横竖伪元素，只保留独立闪烁、柔和光晕和小范围漂移的圆点。
- 流星使用 Web Animations API 实现连续直线位移、平滑缓动、渐入和渐隐；每波随机出现 1～3 颗，从左边缘外进入，在屏幕上半区沿不同轨迹向右上方运动，并在 1.9～2.6 秒后从上边缘离开，不进入右侧地球主体。
- 打印、全页渲染与减少动态效果环境不启动随机调度；派生 HTML、IR、build id、PDF 和 PNG 继续保持确定。

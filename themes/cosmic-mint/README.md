# Cosmic Mint 主题

`cosmic-mint` 是从用户参考图提取并完成用户验收的深色宇宙主题，当前版本为 `0.1.5`。它使用薄荷青作主强调、冷白文字作主要内容，并以铺满演示舞台的颗粒化斜向银河、独立闪光和小范围漂移的圆点星空、右侧陆地点阵地球，以及从左边缘进入并从上边缘离开的随机多流星构成识别性背景。

## 适用场景

- AI、工程、技术培训和未来感主题。
- 需要明确标题层级与少量高亮的演示文稿。
- 深色环境下的现场展示和屏幕录制。

## 设计边界

- 不复制参考图的栅格背景、平台 UI、直播评论或品牌元素。
- 银河和地球由主题自有的代码生成 SVG 重建，不嵌入参考图背景；构建时 SVG 会内联到 CSS，最终 HTML 保持自包含。
- 地球只在陆地区域使用细小点阵，海洋保持深色留空，并以 48 秒纹理漂移表现缓慢转动。
- 每页使用 15 颗确定性圆点主星；每颗拥有独立周期、负延迟、亮度峰值、光晕和 4～12px 漂移轨迹，不添加十字光芒，也不使用成组同步透明度动画。
- 演示会话只从 `crypto.getRandomValues` 获取一次种子，再由内部 PRNG 调度流星波次；每波出现 1～3 颗细流星，轨迹、长度和启动偏移不同，从左边缘进入、沿屏幕上半区向右上方飞行，并在 1.9～2.6 秒后从上边缘离开，不穿过右侧地球主体。
- 双栏与对比卡片按内容高度自适应，同排保持等高，但不强制占满页面剩余高度。
- 非 16∶9 视口使用与页面同源的银河、渐变和稀疏星光延展到视口边缘，逻辑画布仍保持 1280 × 720，不拉伸或裁切内容。
- 打印、全页渲染和 `prefers-reduced-motion` 环境不会启动随机流星调度，并冻结其余背景动画，保证 PDF、PNG 与无动画预览稳定可复现。
- 参考图与用户反馈图仅限本地分析，`references/reference.png` 和 `references/feedback-*.png` 被 Git 忽略，不得公开推送。
- 图表和摄影规则属于低置信度设计延伸；地球与流星动效由用户书面反馈确认。

## 验证

```bash
npm run check:themes
PLAYWRIGHT_BROWSERS_PATH=0 npm run html-ppt -- check themes/cosmic-mint/specimen.md \
  --theme cosmic-mint --strict --output output/cosmic-mint-specimen-check
```

执行 PNG 导出时，本地参考图会被嵌入 `theme-review.html`，便于将原图、Style Spec、Manifest、token 和全部页面并排审核。动态速度与地球纹理变化必须在 `index.html` 中复核，PDF、PNG 和审核页只展示稳定静态帧。
